# SuperKart Frontend App

This folder contains the Streamlit frontend for the SuperKart sales forecasting model.

## Files

- `app.py` - Streamlit frontend application
- `requirements.txt` - Python dependencies
- `Dockerfile` - Frontend container definition

## Features

- Single prediction
- Batch prediction
- CSV upload
- Download prediction results

## Container Port

The frontend application runs on port `8501`.

## Backend URL

When running using Docker Compose, use:

```text
http://backend:5000
```
